# Meine

App iOS, SwiftUI. Phim, nhạc, truyện tranh, truyện chữ. Không có nguồn cố định.

Mở [Meine.xcodeproj](Meine.xcodeproj) rồi build theo [docs/03-BUILD-IPA.md](docs/03-BUILD-IPA.md). Signing đã tắt để đóng IPA unsigned.

Hợp đồng nguồn: [docs/source-protocol/README.md](docs/source-protocol/README.md). Nền mặc định xanh biển pastel và trắng.

Nguồn mẫu: `docs/examples/local-demo`.
