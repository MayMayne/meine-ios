# Lộ trình code

Đừng viết player trước khi một nguồn local mở được.

1. Model manifest, home, item. JSON hỏng không crash. Đã có trong Sources/MeineCore. Chưa có model item đầy đủ.
2. Thêm thư mục Files, lưu bookmark, mở lại sau khi tắt app.
3. Trang chủ từ section, theme pastel mặc định.
4. Khoá nguồn trong Keychain.
5. Nhạc: phát file, rồi lyric LRC, full và nửa màn.
6. Truyện chữ: cuộn, nền, font. Dịch và TTS sau.
7. Tranh: webtoon trước, trang lẻ sau.
8. Phim: MP4 hoặc HLS, gesture, sub mềm.
9. Feed clip dọc.
10. HTTP, rồi WebDAV, Drive, OneDrive.

Mỗi bước chạy với `docs/examples/local-demo`.
