## Bốn engine nội dung

**Truyện chữ:** EPUB dual-strategy (TOC rồi regex Tập/Chương). Lazy load từng xhtml. Dịch in-place 3 phần (glossary, genre prompt, negative memory). Cache SwiftData SHA-256. TTS + bảng phát âm + SSML. TextKit 2. Font otf/ttf + fallback dấu Việt. Nền/chữ có slider. Lật trang và cuộn, có auto-scroll.

**Truyện tranh:** Webtoon mặc định. Lật LTR/RTL, trang đơn/đôi. Tap zone: trái-phải, Kindle, chữ L, viền. Metal smart invert, contrast. Ring-buffer preload. Hỗ trợ cbz/zip và thư mục chapter.

**Nhạc:** EQ 10 band (32 Hz … 16 kHz) qua AVAudioEngine. Gapless + crossfade 1–12s. Lyric lrc/srt/ttml, nửa màn và full màn, syllable glow. Fluid mesh từ màu bìa. Thiệp chia sẻ lyric 9:16 và 1:1.

**Video:** VideoToolbox trước, FFmpeg khi MKV/DTS/track lạ. Vuốt trái sáng, phải volume, hai ngón tua. Sub mềm SRT/ASS/SSA. Danmaku. Shorts: slot N-1 / N / N+1, prefetch ~2MB.

## Local folder convention

- Phim: `Title (Year)/file.mp4` + `.vie.srt` + `poster.jpg`; series có `Season 01/S01E01.mkv`.
- Truyện tranh: `Title/cover.jpg` + `Chapter 001/*.jpg` hoặc `Chapter 002.cbz`.
- Nhạc: `Artist/Album/cover.jpg` + audio + `.lrc`.
- Chữ: `.epub` hoặc `.txt` chia chương bằng regex.
